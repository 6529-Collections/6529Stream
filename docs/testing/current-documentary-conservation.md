These source fixtures exercise `MUSEUM_GRADE_LITE` on the original current stack.
They are separate from the [explicitly WAIVED campaign](current-sale-conservation.md).
Source review and ABI compilation do not establish runtime acceptance, fitting
Artist deployment, production readiness or the 500,000-gas collector target.

## Paid flows and independent model

`StreamCurrentDocumentaryConservationTest` covers original EOA and literal Safe
native purchases, first documentary evidence, repeated semantic content, General
supersession, late missing-master failure and exact retry, source append, transfer
and completed burn. Its model compares every original DIRECT receipt word, the
complete first-sale and release receipts, and the complete DIRECT floor tuple.
It derives receipt domains, keys, source heads and media inventory independently.
It retains complete source rows and all prefix heads across replacement.

General supersession makes a selected native reference stale. The actual Artist
mint prerequisite therefore rejects Manager preview before payment or the Floor
call, even after a successful historical sale. Tests prepare the purchase while
eligible, supersede the report, verify rejection, refresh operation 24, and retry
the identical commercial bytes. The first sale's historical summary is permanent.

A new media manifest with no master fails at the late Floor call after the
original payment/mint path. Each unique failed/successful authorization pair must
make exactly two Floor calls; the original adapter makes one per execution, so
the successful retry alone cannot satisfy the expectation. Tests check the exact EOA
wrapped failure, and compare payer balances, wallet proceeds, liabilities, Core
allocation and lifecycle, Manager replay, Ledger counters, entropy and every old
receipt. A failed Safe transaction may consume its outer Safe nonce; inner
commerce changes must roll back. Completing only the original master evidence
allows the unchanged signed purchase to retry.

## Stateful campaign

`StreamCurrentDocumentaryConservationInvariantTest` targets only its single
handler's `step(uint256)`. The first nine steps require these operations:

| Step | Required checked action |
| --- | --- |
| 0 | EOA documentary purchase |
| 1 | Literal Safe purchase reusing the release |
| 2 | General supersession, early rejection, real op24 refresh and identical Safe retry |
| 3 | New General report and native selection, then EOA purchase |
| 4 | New occupied release, missing-master failure and identical EOA retry |
| 5 | Another new release, missing-master failure and identical Safe retry |
| 6 | Real delayed source append and purchase |
| 7 | Actual current-owner transfer |
| 8 | Actual current-owner burn |

The opening produces seven paid mints, two new releases and one burn. Later seeds
choose all nine operations. Every dispatch must change checked Core supply or
custody and pass the full model before its counter advances. Activity assertions
require all opening actions and at least one random step. Sensitivity cases reject
no activity, a missing random tail, unauthorized dispatch, a wrong payer debit and
missing historical first-sale evidence.

Supported invariant depth is at most 256. At that bound there are at most 254
purchases and media variant 250; the fixture supply limit is 512 and variants do
not wrap or skip actions. The quick campaign uses seed `0x6529`, 256 inputs per
fuzz property, 32 sequences at depth 64, one worker, `fail_on_revert=true` and
`check_interval=1`. The separate seeded property executes the nine-step opening
and sixteen hashed-seed tail steps. Extended work may use 4,096 property inputs
and 256 sequences at depth 256 after the selected current graph fits and runs.

## Gas and execution qualification

The dedicated documentary fixture uses provider READ 300,000 / SOURCE 1,000,000,
Floor PRODUCER 4,000,000 / CALL 6,000,000, and a retained optional reference budget
that is unused for OFFCHAIN. These are explicitly configured new test instances,
not production defaults, governance increases, or capacity acceptance. The Floor
call is the original DIRECT call after Manager returns; this does not establish
that the same values work inside a prepared auction's Manager callback.
The new master selector uses MANIFEST_READ 500,000 (floor 500,000) and
COVERAGE_READ 800,000 (floor 500,000). The existing External Archive read budget
remains 500,000. No further automatic budget adjustment is authorized by these
tests. A second negative diagnostic preserves the rejected master 1,000,000
child reservation inside a provider source call capped at 1,000,000.
The production constructor requires both master read floors to be at least
500,000. A separate constructor regression retains rejection of the proposed
manifest 300,000 / floor 100,000 configuration; no production rule is relaxed.

A separate negative diagnostic preserves the original incompatible provider
SOURCE 8,000,000 / Floor PRODUCER 1,000,000 / CALL 6,000,000 reservations. The
provider requires child cap plus EIP-150 and return headroom before calling its
source, so the original combination fails independently of execution cost.

The current host includes budget probes for real collection and occupied-release
proofs and emits measured execution gas. Explicit cooling covers named accounts;
it is not proof of a complete cold storage/blob/library closure and excludes
transaction intrinsic gas. All nested actual proof work remains present. Any
reservation or workload failure must remain visible, and no further allowance
increase is implied. The ordinary transaction and collector targets remain open.
Each actual EOA buy and outer Safe execution is separately capped at 16,777,216
minus 21,000 base gas and the literal outer calldata's 4/16 gas-per-byte cost.
The positive-value EOA CALL requests 2,300 gas less to account for its added value
stipend; the zero-value outer Safe CALL needs no stipend adjustment.
This bounded execution retains the original transaction envelope; warmed
preflight reads still prevent treating it as complete cold collector acceptance.
