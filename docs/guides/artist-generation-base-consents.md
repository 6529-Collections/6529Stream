# Recovered pending generations with direct policy, economics and sale history

This additive operation60 composition supports one original class1/class3 recovered Artist and
one PRIMARY_ONLY, mode1 collection whose complete original binding history contains2–128
pending generations. Every earlier generation must be refused or withdrawn, and only the final
generation is accepted. It adds complete direct14/15/16 histories with at least one original15
or16 and no17/20/21 occurrence. The existing request, entrypoint, original signing domains,
records, replay cells and seven-owner atomic import remain unchanged.

## Exact codec and capability selection

The owner6 semantic payload is the deterministic encoding:

```solidity
abi.encode(
    keccak256("6529STREAM_ARTIST_RECOVERED_GENERATION_BASE_CONSENTS_V1"),
    uint16(1),
    uint64(finalGeneration),
    originalContentBundle
)
```

`originalContentBundle` retains the original nominal ContentConsentHydration.Bundle type. Its
three content, royalty-freeze and content-freeze arrays must all be empty. The original base
bundle contains every14 policy,15 economics association and16 sale row from the authenticated
flattened owner6 journal. It is not a caller-selected subset. The exact final generation is
first joined to the complete original owner0 history and current Attribution, then committed
in this canonical tag and checked against every original economics/sale generation.

All seven export headers require BINDING_GENERATIONS512. DIRECT_ECONOMICS32 is set exactly
when15 occurs; the existing DELEGATED_CONSENT64 transport capability is set exactly when16
occurs, as already required for direct sale records. CONTENT_CONSENTS256 is absent. The bit64
name does not imply a delegate: this slice requires every recorded grant association to be
zero and the complete Identity grant inventory to be empty. Unused, expired or revoked grants
are not projected away.

Original generation1 codecs and their imports are unchanged. The earlier generation-only14
and optional24 profile still uses its original policy payload bytes and original import route.
The separate content-bearing generation codec still requires a real17/20/21 occurrence. None
of these payloads can be relabeled as another profile by changing only a feature flag or tag.

## Complete history, witnesses and import

Original15 terms are supplied by the existing complete collection witness and checked against
actual source maps, full original association/hash, native receipts and replay admissions.
Missing, extra, duplicate or foreign terms fail. Original16 already retains its full preimage,
so a sale-only source with no24 needs no documentary witness. Optional complete24 histories,
C2PA/personhood records, readiness, original Identity and Payout history retain their existing
supported composition and exhaustive source joins.

Preparation uses actual full source journals and headers. No source history is omitted to fit
a codec. Complete Identity nonce/signature/revocation facts and every original environment,
receipt, revision and replay alias remain required. The fixed consent worker authenticates the
new tag before reusing its original seven typed storage maps and original write order. Its
content-head half has no writes for the validated empty arrays. The concrete Owner, Identity,
Commit and Writer sources are unchanged; original operation60 authority and postapply source
reread still precede the final atomic Archive receipt. A failure restores every owner and the
Safe nonce, and the exact signed request can be retried after the external fault is repaired.
