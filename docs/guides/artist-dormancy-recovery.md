# Recovery after designated dormancy

This additive reader admits the first elected recovery of a designated class-3
successor installed by original operation 43. It uses the existing operation 35
payload, new-address Safe acceptance, staged TERMINAL_FREEZE action registration,
guardian veto and atomic Archive. The historical 1–57 operations, dismissal 58 and
later steward-grant 59 retain their own recipes and signing domains.

## Original appointment proof

The current fixed Identity must have an actual completed dormancy origin and its
original notice. Both full stored records are independently reconstructed under
their admitted domains. The terminal's notice, class, original authority, plan,
action/witness commitments, execution time and delegation epoch must agree with
the original transition and canonical operation-43 vesting snapshot. Historical
governance is consumed as admitted immutable owner history; it is not reauthorized
against today's roles or timing parameters.

The currently operative living-artist designation and directives must be exactly
the saved plan, with canonical hashes, original signing class and eligible
associations. Capabilities are recomputed from that plan. A preceding living
operation-32 rotation is supported through its canonical immutable snapshot and
record: the latest-head link, address/time/revision continuity and guardian prefix
remain joined. An earlier plan signer is retained; no mutable retired-address
mapping is used as an ancestry anchor.

The current compromise must be the actual original operation-33 record naming
this appointment and the requested evidence/reason. It must have been filed at
or after the original post-vesting window. Waiting does not mature an earlier
compromise. The profile has no prior recovery, intervening rotation, prior cause,
resolution or closed appointment. It refuses enumerated supersession; the broader
dormancy-origin adjudication and closure profiles remain separate unfinished work.

## Guardians, authority and execution

The full saved guardian prefix and current complete owner history remain intact.
A living guardian set can remain selected, including an eligible set written
around an earlier living rotation. A later class-3 set must have been written by
the original appointed successor after the vesting index/revision and carry the
exact eligible original association or a valid empty association. Highest eligible
nonce selects the operational set; lower-nonce lifetime records retain veto.

The new request and original acceptance are registered with the exact guardian
and history snapshot before execution. The same original mutation consumes the
acceptance, cause, governed action and retirement replay cells, appends the three
original recovery receipts, advances the delegation epoch, and installs class 3.
The operation-43 appointment and original capability origin are never rewritten.
An Archive failure rolls every mutation back, allowing identical signed inputs
to retry after repair.

This path cannot grant living class 1 or steward class 4 from the designated
successor. AA-ROTATE requirement 7 defines recovery output classes 1 and 3; it
does not define a new class-4 recovery recipe. Steward-origin recovery to a proved
living artist or rightful estate is still a separate authority profile.
