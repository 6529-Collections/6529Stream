# Recovered pending-generation content consents

This bounded operation60 composition combines complete original pending proposals,
refusals and withdrawals with the final accepted mode1 collection's direct consent
history. It adds no Registry selector, signature, writer or storage namespace.

## Supported source

One recovered class1/class3 Artist and one PRIMARY_ONLY collection may have two
through128 original binding generations. Every earlier generation is refused or
withdrawn, and only the last is accepted. Complete owner6 history may contain
14/15/16/17/20/21; at least one17/20/21 selects this content profile. Existing
complete Identity/Payout recovery and original24 readiness, publication, C2PA and
personhood histories can accompany it. All policy, economics, sale and royalty
grant associations must be zero, and the full Identity grant inventory must be
empty. Historical direct consent is not reauthorized against today's principal.

Use the existing `hydrateRecoveredArtistAuthorityWithConsents(Request,royalties)`
when original20 terms are needed. The existing Request witness supplies every
original15 term and24 input in source order. Counts and subjects come from complete
authenticated native journals, not caller enumeration. Royalty terms likewise
match every original20 scope-keyed record in journal order. Neither omitted
preimages nor current grant heads can substitute for saved original facts.

## Codec and joins

Owner6 semantic bytes for this composition are exactly
`abi.encode(keccak256("6529STREAM_ARTIST_RECOVERED_GENERATION_CONTENT_CONSENTS_V1"),
uint16(1),uint64(generation),originalContentBundle)`. The original nominal Bundle
is unchanged. Canonical decoding, the exact new tag and complete validation run
before any import write. The all-owner export header additionally requires the
existing content256 and generation512 capabilities; other required features are
selected from the actual complete history. Original op60 evidence/commitments
cover these exact bytes and all seven owner headers.

The complete original Binding generation proof supplies the accepted generation.
Every content, royalty, freeze, sale and economic association row must match it.
Owner6 native/replay counts, record order and per-era revision equations remain
the original ones. Owner4's first-era `2*generation` mutation base and later
import-only revision base remain distinct from owner6 and Identity clocks.
Original Identity signature, nonce, replay and journal proofs remain complete.
No cross-owner revision comparison is introduced.

The original Consent owner is byte-identical. Its existing fixed importer reads
the authenticated tag/generation, then uses the same declared mapping roots and
precheck/write order. Association keys, latest content scopes, royalty keys and
freeze lookups use that exact generation. Its returned original Bundle already
contains the validated generation in every17/20/21 row; the second import half
uses those values, never a current-binding lookup or caller-supplied substitute.
Original record hashes/domains and historical receipt coordinates remain exact.
Repeated17 terms and overlapping21 lock sets retain the actual last record.
The existing late source recheck, one atomic seven-owner import and Archive
publication remain unchanged. Fresh successor actions need original current
authority and fresh successor-domain signatures; imported nonce guards stay used.

## Compatibility and limits

Generation1 entry points, old nominal Bundle/schema/selectors and encoded bytes
remain unchanged. Prior generation-only14/24 histories keep their existing codec.
Generation-aware economics/sale-only histories without17/20/21 use the separate
[base-consent generation profile](artist-generation-base-consents.md). Mode2/delegations,
accepted-binding corrections53, collaborators, class4 and wider collection/Artist
combinations remain separate required compositions.
The new entropy configuration family is explicitly refused. Original Artist op17
terms, records and domains are retained; they do not grant fresh external authority.
Operation60 keeps the same selected Router, so its VIEW profile map is not copied by
Artist migration. A genuine Router replacement has its own tagged continuity scope.

## Verification scope

Seven new actual Artist/Registry/Coordinator/Archive/threshold-Safe recipes cover
mixed generation3 history, repeated imports, correct-generation heads, witnesses,
source/capability/codec/grant refusals, spent nonces and exact late-Archive retry.
The failure/retry oracle counts two calls to the same independently derived first
evidence page, so a premature failure cannot be hidden by the successful retry.
Two stage cases test exact original15/24 witness and20 term counts. Core,
governance, Metadata and sale facts retain explicit typed fixture boundaries.
These are authored/typechecked cases; no runtime, maximum-carrier, full-current
graph or release acceptance is claimed here.
