## Governed VIEW route budget

`IStreamViewRouteReadBudgetV1.viewRouteReadBudget()`. It returns the profile
`keccak256("6529STREAM_GOVERNED_VIEW_ROUTE_READ_BUDGET_V1")` and the `readGas`

rejects this call while its once-only governed binding is pending. After binding,
the value is fixed; this inexpensive getter does not assert complete currentness.

constant-shape reads. The global parameter and the maximum snapshot validation

be at least its read budget. An advertised pending or malformed capability fails;

validation. Adoption, both original current-source readers, and the new
preservation root reader use the same selection rule. Existing runtime pins,
