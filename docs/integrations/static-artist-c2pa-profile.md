# Named Artist/C2PA STATIC source profile

This finite companion profile clarifies the named source set under
[MRR-DETERMINISM rule 3](../metadata-router-and-renderer.md#renderer-determinism).
The integrator approved these declaration labels for the original Artist
attribution and optional C2PA paths. A label grants no authority and does not
authenticate an address as the named implementation.

The existing `CORE`, `COLLECTION_METADATA`, `METADATA_COMPANION`,
`DEPENDENCY_REGISTRY` and `ENTROPY_COORDINATOR` roles remain accepted. The
additional roles are exactly:

| Role | Source |
| --- | --- |
| `STATIC_C2PA_ATTRIBUTION` | Optional attribution wrapper |
| `C2PA_RECONCILIATION` | Selected verifier report companion |
| `ARTIST_REGISTRY` | Original Artist facade |
| `ARTIST_STATIC_DISPLAY` | Fixed linked Artist display worker |
| `ARTIST_COORDINATOR` | Original suite configuration |
| `ARTIST_IDENTITY_OWNER` | Suite owner 2: operative identity and authority facts |
| `ARTIST_BINDING_OWNER` | Suite owner 0: original binding and collaborator terms |
| `ARTIST_ATTRIBUTION_OWNER` | Suite owner 4: attribution and direct credential heads |
| `ARTIST_COLLABORATOR_RECORDS_OWNER` | Suite owner 1: accepted collaborator records |
| `ARTIST_ACCEPTANCE_OWNER` | Suite owner 3: original acceptance facts |
| `ARTIST_SANCTION_OWNER` | Suite owner 6: sanction display facts |

Every deployment still pins an immutable sorted set of exact addresses, runtime
hashes and roles. Limits remain 64 targets and 128 sorted unique reads, each with
its selector and fixed-shape or maximum returndata cap. Generic Artist-owner
roles, arbitrary metadata roles, and OwnerRecords/default-view roles are absent.
The OwnerRecords MARKETPLACE firewall remains binding.

Registration still requires the original governed action, complete performed
transitive STATIC analysis and retained golden vectors. Runtime/link provenance
and the semantics of every source must be independently verified; constructor
acceptance of a role is not that verification. The original attribution closure
must remain in the inventory when C2PA edges are added.

Live adverse provenance remains mandatory under MRR-ATTRIBUTION rules 3/5/6,
AA-DISPLAY rule 7 and CMC-C2PA rules 10/11. This profile does not freeze those
annotations. Preserve original full-output hashes as historical checkpoints:
changed live annotation bytes make those checkpoints stale. Separating stable
artwork bytes from live annotations would require an explicit separate profile.
Frozen Artist source `3f1a0680` also needs the pending conflict-history successor
before the optional paired path can claim complete ART38 behavior. No STATIC
admission, byte-exact finality, native execution or deployment-size acceptance
is established by this addendum.

The focused registry tests use synthetic targets and analysis documents to test
labels, pinned target identity, read bounds and admission gates. They do not
claim an analysis of the actual Artist/C2PA graph.
