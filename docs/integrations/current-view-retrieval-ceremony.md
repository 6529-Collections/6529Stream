## Source and observation entry points

Call `exportViewRetrievalSource(directory, sourceRevision)` in a fresh recipe.
It prepares the actual original source and image Archive pair before exporting
the original complete `source.json` and per-member outputs. It additionally
writes `adopted-image.png` and, last, `retrieval-source.abi`. The returned three
words are the original source hash, `source.json` SHA-256, and retrieval-envelope
SHA-256. The envelope binds the original export, chain, test host, witness
runtime and full configuration, complete scope/adoption/payload, both exact URI
strings, complete original object and coverage, institutional family/Safe, and
full PNG bytes. Preserve the genuine compiled host and deployment coordinates
when replaying an export.

`runSuppliedViewRetrievalFinalityFiles` requires both caller-pinned exports,
the explicit source revision, actual environment/browser/capture files and the
complete package-member directory. It compares the complete reconstructed
retrieval envelope as bytes, alongside the inherited complete original source
comparison. It supplies no browser observations or package defaults. A browser
producer must disclose how the reserved origin's fixture bytes were served;
the retrieval fixture is not evidence of public network availability.

The continuation publishes a Safe witness, revokes it through an actual Safe
transaction, and signs a new observation with a distinct nonce before coverage.
The original stage8 witness, seven-row artwork segment, image ordinal5, complete
row bytes, absolute item index and saved original admission are checked around
`coverRetrievalNext`. All other occurrences use the original coverage path.
After complete coverage, a genuine failed fixity makes correspondence and the
cached bundle unusable. A signed repair restores the same receipt pair, and
every ordered bundle item must refresh before current coverage succeeds.

The continuation then uses the inherited original input, nine-component,
Artist-sanction/archive and governed scoped-finality ceremony. It independently
checks the resulting review's one media hash against the full PNG object and
each ordered reference hash against its original capture coverage. It does not
raise any governed, constructor, callback or transaction limit.

## Authored cases and evidence boundary

Two new default cases cover the actual adopted source and Safe witness through
revocation/new-nonce reprepare, and a failed original fixity followed by the
identical signed request succeeding after repair. They deliberately assert that
this source/Archive work has not created a reference observation, sanction or
finality. The complete supplied-observation entry is a separate authored recipe;
it needs real external observations and subsequent measured execution.

Revocation is permanent. Reprepare creates a new signed witness before coverage;
it never unrevokes history or swaps an entry in an already completed bundle.
The Archive repair scenario restores currentness through the original same-pair
and full refresh machinery. Post-coverage witness revocation, when used, requires
new admissible evidence and a new inventory/bundle context rather than a rewrite
of the old completed mapping.

The source/type check includes both the original empty-image host and this new
host. It is not native execution or a capacity result. In particular the actual
fixture's witness source budget14m is nested under the existing bundle archive
budget8m: that integration cannot be presumed executable. The fixture retains
those values so a measured gate reports the real incompatibility. The existing
16,777,216 transaction envelope and maximum-scope requirements remain open.
