# Explicit STATIC metadata routing

This source batch adds an actual `StreamRendererV1`, Router configuration/serving, and
direct raw Metadata source reads. It is source/type checked with eleven authored focused
recipes. Runtime, code size, genuine current Core/Artist/Executor composition, complete
transitive opcode/read-set acceptance and finality composition remain unmeasured or pending.
The word STATIC names the required version class; ABI success alone does not accept that gate.

## Activation and authority

The original Router constructor/storage roots and old configuration methods are retained.
A collection uses the new path only after `activateStaticMetadata(collectionId, expectedDefaultRecord)`.
Activation requires zero lifetime mints, no first-release ratification, no Core freeze, an
unlocked renderer family, the exact current default, and a currently assignable registered
version. The collection-specific immutable activation record retains its original global
default revision and previous-record link. Changing the global default affects only later
activations. Resolution is token override, collection override, recorded activation default.
There is no floating rewrite of already activated scopes.

The currently selected Metadata host's original `IDENTITY_DISPLAY` grants authorize the
caller: class 8 for global defaults, class 7/8 at collection or global scope for overrides.
The record's companion authorization retains that actual Metadata host/runtime, caller,
class, grant scope and revision. It is recorded and emitted alongside the complete config.
After the original consent/mint boundary, overrides use the original op17 consent lookup,
consumed map and ratification continuity under the additive `RENDERER_CONFIG` family.
The original op21 `RENDERER_CONFIG` lock is permanent and Core freeze also blocks edits.
A collection config freeze prevents later token overrides and original render-field edits.
A frozen global default cannot be changed; each later activation separately captures its
source at activation. A token freeze retains its exact raw Router source snapshot so future collection edits
cannot change that token's executable source. No old freeze is assigned a fabricated snapshot.

The namespace commits immutable version, renderer runtime/context/schema/read-set and
registration identity. Every changed override extends the collection's explicit history
head, so token override changes are included in collection content-consent/finality facts.
Existing unactivated content preimages remain unchanged. Failed writes roll back authority,
consent, config and event state atomically. A repeat of the same override is refused.

## Rendering and source evidence

`StreamRendererRegistryModule` makes the governed registry eligible for actual ModuleRegistry
admission; the underlying immutable version/gate records stay unchanged. Its bounded
manifest-output declaration ceiling is 16 MiB, above the structural worst case for full
script/library bytes, sixfold JSON escaping, repeated library context and HTML base64;
this does not raise the 24,576-byte default URI limit. The concrete renderer separately
pins Core, Router, Metadata, original entropy coordinator, optional dependency registry and
attribution companion. New assignment checks the current original registered manifest.
Deprecation blocks new assignment/activation while an already pinned version remains readable.

The Router builds the real request from retained Core token identity/lifecycle, original
coordinator, seed/status, collection supply/status and resolved immutable config. Burned
ERC721 tokenURI remains refused; full methods retain burned disclosure. Pending requests
omit seed/hash context, and executable full HTML requires finalized entropy. OFFCHAIN uses
the explicit token-id/collection-serial URI recipe and optional pending URI; ONCHAIN and
HYBRID provide versioned JSON/HTML without fetching or executing an offchain source URI.

The named Router companion reads its own raw display fields without a linked renderer.
Metadata `staticScriptManifest`, `staticBundle` and `staticBundleChunk` directly copy the
original owner mappings with no external call. The renderer reconstructs every original
logical chunk from exact STOP-blob pieces or the original pinned dependency version,
checking sizes, per-chunk/full payload hashes and the original registry rolling commitment.
It retains all 32 x 24,576 script bytes and optional separate library.
`scriptBundleChunk(bundleId,index)` uses the same exact reconstruction routine as assembled
output; `scriptBundleFacts` provides the immutable ordered-payload commitment. The selected
manifest identifies the script bundle and its facts identify the library bundle. A page
proves its saved chunk; clients additionally verify the complete ordered payload hash.
The output envelope does not establish a worst-case execution-gas result. It escapes closing
script tags only after complete reconstruction and uses the original pure UTF-8/JSON logic.
Compact output links the actual full `tokenJSON`/`tokenHTML` methods; a reference is never
represented as a complete executable export. Large attribution retains its actual state
and points to full details rather than being relabeled unavailable.

Golden `RenderRequest` values are inputs, not token existence evidence. The explicit
zero-config/zero-token source can render a deterministic empty pending vector before any
mint exists, breaking the otherwise circular register-before-assign dependency. Actual
Router dispatch always requires real retained token identity and a nonzero selected record.
Synthetic golden/source boundaries in the authored tests do not prove current-contract mint
or institutional/artwork acceptance.

## Shared source and finality dependencies

The transitive rule applies through source-host internals. Existing Artist facade and
entropy getters use fixed delegatecall codecs and are not accepted by this profile. The
new consumer requires the closed Artist transport in `static-artist-source.md`, and
`IStreamStaticEntropySource.staticTokenRenderFacts` (96 exact bytes). The latter copies
original `_subjects[_tokenKey(tokenId)]` status/seed and the saved request-policy provider,
falling back to `collectionEntropyConfig[subject.collectionId].provider` only when the
original requestKey is zero. It must never substitute the current provider epoch.
A missing Artist transport yields the explicit bounded attribution-unavailable fallback;
a missing entropy source fails rendering. A and the integrator own those source additions.

The attribution companion preserves the original complete fact/identity/claim/attestation/
sanction checks and pure serializer, with constructor-bound Router identity and saved chain
ID replacing delegatecall context. Its existing finality/snapshot/membership source chain
also requires the transitive gate. ScopeMembership now uses internal copies of its exact
original bounded read and seven-fact
membership hash in serving paths. The original public helper ABIs and publication path remain
unchanged. Four authored cases disable the linked helper runtimes after publication and check
same facts, pending prefixes, burned tokens, malformed Core data and changed recorded blobs.
This removes that known serving seam; it does not substitute for whole-program opcode analysis.

Provisional Artist identity maturity is a separate dependency: the original live getter uses
current time. The Artist producer is adding an explicit permissionless checkpoint after the
original eligibility succeeds. STATIC must require that exact checkpoint and recheck its live
stored association/transition facts, using no timestamp. Until it exists, the optional identity
frame is explicitly unavailable; an old stable name must not be relabeled the current document.

Activated `collectionServingFacts` uses distinct `6529STREAM_STATIC_METADATA_SELECTION_V1`
with the exact selected renderer. Prior finality providers must reject that profile rather
than derive new output from old linked-renderer snapshots. A dedicated finality producer/
consumer must bind selected config plus its actual source snapshot and original renderer
read-set before this route is accepted for finality. This batch does not silently route a
new finalized scope to current bytes or claim the prior profiles are upgraded.

## Focused recipes

The eleven authored cases use actual Router/Renderer/Metadata/Schema/SSTORE2 and official Safe
1.4.1 bytecode. Core, Artist/attribution, registry admission and governance scheduling are
explicit typed boundaries. Oracles cover independent config hash/default revision,
current-state disclosure, opaque token bytes, frozen token source retention, original op17
one-use consumption, exact failed Safe transaction retry, OFFCHAIN serial/pending behavior,
burned reads, retained deprecated versions, renderer-family freeze, complete logical SSTORE2
reconstruction and deterministic pre-mint golden inputs. They have not been executed.
