# Local General review capture

This fixture exercises the retained General V2 signed and curator paths on an isolated loopback Anvil chain. It deploys the real Core, Governance Executor, Schema Registry, Metadata module, and General Attestations host. A governed `CURATOR` family/class 3 grant permits two original curator publications; the grant is then revoked, while the historical receipts remain readable. The institutional mapping and estate review use the host's signed publication path. The fixture stores original source, publication, semantic, selection, and graph bytes for offline replay.

The 30 native products came from explicitly qualified historical compiler contexts, pinned by the retained `native-inputs.json` and `native-reuse-audit.json`. Five main sources differ from this checkout: `StreamCollectionMetadataV1`, `StreamCore`, `StreamCoreExternalReads`, `StreamGeneralArtistEvidence`, and `StreamMetadataRenderer`. `GeneralArtistBoundary` is a compiled typed fixture used only to satisfy constructor bindings. The Artist lane is empty and no Artist statement was executed. This fixture does not establish a current-source or whole-stack deployment, independent people, institutional identity, consensus finality, custody, title, or accession.

It contains local chain addresses, transactions, receipts, and compiler artifact references, with no private keys. Run `python -m unittest tools.museum.test_general_review_capture_v1 -v` to verify the retained packet without an RPC. It replays source, publication and selection, checks the two signed/curator approvals, proves that an admitted rejection withholds the exact mapping, and confirms that author self-review needs an explicit policy opt-in. To repeat the local capture, use `python -m tools.museum.general_review_capture_v1 --native-manifest PATH --native-manifest-sha256 SHA256 --native-reuse-audit PATH --native-reuse-audit-sha256 SHA256 --output NEW_DIRECTORY --disclosure public`. The command starts and terminates its own loopback Anvil process; it does not contact an external chain or compile contracts.
